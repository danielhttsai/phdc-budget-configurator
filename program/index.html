Multi-Country RWE Program for Clinical Trial Design and Planning

Real-world data from the AsPEN network, used to answer the questions a protocol has to settle before it is written: where the patients are, how many survive the eligibility criteria, how many events to expect, and which endpoint a trial of realistic size can actually detect.

Programme structure

screen the network, then go deep on what survives
Stage 1

Data and Trial Feasibility

Every feasible AsPEN database is screened once against the research question, before anyone commits to an analysis. The output is a database feasibility matrix and a decision: which databases earn a place in Stage 2, and which are dropped with a documented reason.

data suitability → population size → eligibility → endpoint capture → follow-up → linkage
Stage 2

Study-based Trial Planning Analyses

The formal protocol is run on the databases that passed. One common protocol, one set of variable definitions, one QC pass, executed locally in each country so that no patient-level data leaves its jurisdiction; only aggregate results are pooled.

eligibility scenarios → event rates → treatment pathways → comparative analyses → target trial emulation → transportability
